# Vera Brand Identity

## Colour Palette

| Token | Hex | Usage |
|---|---|---|
| `vera-black` | `#0d0d0d` | Primary background |
| `vera-gold` | `#d4af37` | Primary accent, CTA buttons |
| `vera-surface` | `#1a1a1a` | Card / surface backgrounds |
| `vera-border` | `#333333` | Subtle borders |
| `vera-verified` | `#4caf50` | Verification badge |
| `vera-text-primary` | `#ffffff` | Primary text |
| `vera-text-secondary` | `#aaaaaa` | Body / secondary text |
| `vera-text-muted` | `#666666` | Fine print, labels |

## Typography

- **Display**: Inter Black (weight 900) – logo mark, hero headlines
- **Body**: Inter Regular (weight 400) – body copy
- **UI**: Inter SemiBold (weight 600) – labels, buttons

## Logo

The Vera wordmark uses the full-caps VERA typeset in Inter Black with
letter-spacing 8px on a `#0d0d0d` background.  The gold (`#d4af37`) accent
colour communicates premium positioning.

Placeholder logo files should be replaced with production-ready SVG exports
from the Figma design file before launch.
